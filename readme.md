# TeamFinder

> **TeamFinder** — это современная веб-платформа для поиска единомышленников, создания проектных команд и совместной разработки IT-продуктов. Проект призван объединить разработчиков, дизайнеров, менеджеров и других специалистов, позволяя им находить интересные стартапы, присоединяться к существующим командам или собирать людей под собственные идеи.

## Основной функционал

### Управление проектами
- Создание, детальный просмотр, редактирование и завершение проектов (перевод в статус **"Закрыт"**).

### Командное взаимодействие
- Возможность в один клик стать участником чужого проекта или покинуть команду.
- **Защита**: автор проекта не может покинуть собственную команду.

### Система "Избранного"
- Добавляйте понравившиеся проекты в закладки для быстрого доступа.

### Кастомные профили
Личные кабинеты участников с информацией:
- Имя и фамилия
- Контактный телефон
- Информация «О себе»
- Ссылка на GitHub

### Автоматическая генерация аватарок
Если пользователь не загрузил аватар вручную, система с помощью библиотеки **Pillow** автоматически генерирует уникальную аватарку:
- Случайный фоновый цвет
- Первая буква имени

### Умная фильтрация
Поиск и фильтрация участников по ролям:
- Авторы избранных проектов
- Участники моих проектов
- И другие критерии

### Высокая производительность
Запросы к базе данных оптимизированы с помощью `select_related` и `prefetch_related` для исключения проблемы **N+1**.

|-----------|-----------|
| **Backend** | Python 3.10+, Django 5.x (Django ORM, MVT) |

## Инструкция по развертыванию

### 1️⃣ Подготовка окружения и установка зависимостей

```bash
# Клонирование репозитория
git clone https://github.com/mitareex/team-finder-ad.git
cd team-finder-ad

# Создание виртуального окружения
python3 -m venv venv

# Активация виртуального окружения
# Для Linux/macOS:
source venv/bin/activate
# Для Windows (cmd):
venv\Scripts\activate
# Для Windows (PowerShell):
venv\Scripts\Activate.ps1

# Установка необходимых библиотек
pip install -r requirements.txt
```

### 2️⃣ Запуск базы данных через Docker

> Для полноценной работы приложения используется СУБД PostgreSQL, настроенная для запуска внутри Docker-контейнера.

```bash
# Убедитесь, что Docker запущен, затем выполните:
docker compose up -d
```

> ⚠️ **Примечание**: Если локальный порт `5432` уже занят, измените внешний порт в `docker-compose.yml` (например, `"5433:5432"`) и укажите новый порт в файле `.env`.

### 3️⃣ Настройка переменных окружения (`.env`)

```bash
# Создайте файл .env на основе шаблона
cp .env_example .env
```

Откройте `.env` и заполните переменные:

| Переменная | Описание | Пример значения |
|------------|----------|----------------|
| `SECRET_KEY` | Секретный криптографический ключ Django | `django-insecure-some-random-hash...` |
| `DEBUG` | Режим отладки (`True` для разработки) | `True` |
| `ALLOWED_HOSTS` | Список разрешённых хостов (через запятую) | `localhost,127.0.0.1,web` |
| `DB_ENGINE` | Движок базы данных Django | `django.db.backends.postgresql` |
| `DB_NAME` | Имя базы данных в PostgreSQL | `teamfinder_db` |
| `DB_USER` | Пользователь базы данных | `teamfinder_user` |
| `DB_PASSWORD` | Пароль для подключения к БД | `super_secure_password_123` |
| `DB_HOST` | Хост базы данных (из docker-compose) | `db` |
| `DB_PORT` | Порт PostgreSQL | `5432` |

### 4️⃣ Применение миграций и создание суперпользователя

```bash
# Применение миграций к БД
python manage.py migrate

# Создание суперпользователя
python manage.py createsuperuser
```

### 5️⃣ Запуск локального сервера разработки

```bash
python manage.py runserver
```

→ [http://127.0.0.1:8000](http://127.0.0.1:8000)

→ [http://127.0.0.1:8000/admin/](http://127.0.0.1:8000/admin/)
